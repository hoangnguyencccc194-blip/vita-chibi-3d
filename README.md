# Vita · nặn mặt 3D (MMD)

Trang web tĩnh (three.js + MMDLoader, không cần build) để chỉnh biểu cảm khuôn mặt của Vita (Honkai Impact 3rd) bằng các morph của mô hình MMD chính thức.

- **Mô hình:** 薇塔 – mô hình MMD chính thức 崩坏3, sự kiện bilibili 「裁梦启明」创作激励计划. 模型版权所属 miHoYo · 模型编辑：神帝宇.
- **Điều khoản:** 允许改造 · 请勿二次配布 · 请勿用于18禁/极端宗教/血腥猎奇/人身攻击 · 请勿用于商业用途.
- Repo này **không chứa file mô hình**. Trình duyệt tải zip trực tiếp từ CDN phát hành chính thức của bilibili (https://www.bilibili.com/blackboard/activity-enUvYDBdNv.html) lúc mở trang.
- Trang fan, phi thương mại. Bản tự dựng cũ ở `v1/`.

Chạy thử: `python3 -m http.server` rồi mở http://localhost:8000/
